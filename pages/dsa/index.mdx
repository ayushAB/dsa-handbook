# 🎯 About This Project

This handbook is a modern DSA preparation platform built using:

- ⚡ Next.js
- 📚 Nextra Docs Theme
- 🧠 MDX Documentation
- 💻 Multi-language examples
- 🎯 Interview-focused learning

The goal is to create a **fast, clean, and structured DSA revision handbook** for coding interviews and competitive programming.
