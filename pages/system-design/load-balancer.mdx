# ⚖️ Load Balancer

A load balancer distributes incoming traffic across multiple servers.

---

# Why Load Balancers?

Without a load balancer:

```text
Users → Single Server → Crash
```

With a load balancer:

```text
Users → Load Balancer → Multiple Servers
```

---

# Benefits

- High Availability
- Fault Tolerance
- Scalability
- Better Performance

---

# Common Algorithms

| Algorithm         | Description               |
| ----------------- | ------------------------- |
| Round Robin       | Rotate requests equally   |
| Least Connections | Send to least busy server |
| IP Hash           | Based on client IP        |
